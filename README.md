Beginner Python project to analyze agriculture crop sales, calculate total and average sales, and identify the highest-selling crop.
# Agriculture Sales Analyzer

## Project Overview
The Agriculture Sales Analyzer is a beginner-level Python project that analyzes sales data for different crops.

## Objectives
- Calculate total crop sales.
- Calculate average sales.
- Identify maximum and minimum sales.
- Find the best-selling crop.

## Technologies Used
- Python
- Python Lists
- Built-in Functions: `sum()`, `len()`, `max()`, `min()`
- List Method: `index()`

## Sample Data
| Crop | Sales |
|---|---:|
| Wheat | 5000 |
| Rice | 8000 |
| Maize | 6500 |
| Mustard | 4000 |

## Key Results
- Total Sales: 23500
- Average Sales: 5875
- Maximum Sales: 8000
- Minimum Sales: 4000
- Best-Selling Crop: Rice

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python agriculture_sales_analyzer.py
```

## Learning Outcomes
This project demonstrates basic Python programming, lists, indexing, calculations, and built-in functions for data analysis.
